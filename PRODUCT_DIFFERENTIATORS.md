# Product differentiators (internal)

Audit date: **2026-10-15**  
Use for positioning drafts only after independent verification. **Do not** publish superiority claims against named competitors.

## Verified capabilities (shipped)

1. **End-to-end content preflight** — social, image, contrast, SR preview, video, batch, website in one product.
2. **Evidence provenance** — automated (axe), measured (contrast), rule-based (caption heuristics), AI-assisted (labeled), human review (wizard).
3. **S1 intelligence** — root-cause grouping, remediation priority separate from axe impact, WCAG 2.2 A/AA coverage matrix.
4. **S2 remediation UX** — Start Here, Fix Lab, grouped AI cache, rescan comparison, fix workflow status.
5. **S3 website review** — up to 25 selected pages, sitemap/crawl discovery, representative URL suggestions, compare viewports, scope transparency, Excel/CSV/JSON/ZIP exports, session-only branding.
6. **Privacy model** — no accounts; minimal server retention; local-first for Phase 1/3/4.
7. **Security** — SSRF Layer 1 + worker auth; Layer 2 required for public scanner launch.

## Intentional non-goals

Certification, legal compliance scores, monitoring SaaS, CMS plugins, auto-fix deployments, overlay widgets.

## Free value principle

Core workflows remain usable without payment; operator configures OpenAI/scanner/Blob for optional server features.
